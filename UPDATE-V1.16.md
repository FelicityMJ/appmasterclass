# Update to DataApp Studio V1.16

V1.16 adds teacher read-only access to every pupil app in a class, editable database field definitions, and a direct **Image URL** choice in the image picker.

## Teacher

Open a class and click a pupil name or **View apps**. The teacher can open any saved app in read-only mode and inspect Data, Design, Blocks and Test.

## Database fields

Each field header now has **Edit** and **Delete** controls. Edit allows the pupil to rename the field or change its data type. Delete removes the field and that column's values from every record after confirmation.

## Image URL

When choosing a fixed image, pupils can select **Image URL**, paste a direct `https://` image address, preview it, and use it without consuming a personal image slot.

No Firebase rule change is required from V1.15.
