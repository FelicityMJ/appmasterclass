# Update to DataApp Studio V1.27

V1.27 fixes the iPhone/iPad installation guidance.

## What changed

- On iPhone/iPad the published app button now says **How to install** instead of **Add to Home Screen**. A normal webpage cannot directly trigger Apple's Home Screen install flow.
- The in-app **Share** button is labelled **Share link** on iPhone/iPad so it is not confused with Safari's own Share/More control.
- The install guide now tells pupils to use Safari's browser controls, then **Add to Home Screen**.
- If that action is missing, the guide says **Edit Actions… → add Add to Home Screen**, then return to the Share menu.
- The guide also reminds pupils to leave **Open as Web App** switched on.
- The teacher Publish instructions now use the same wording.
- Published-app service-worker cache bumped to V1.27.

## Firebase

No Firebase rules or Firebase configuration changes are required.
